1. Custom Hooks

Definition:
A Custom Hook is a reusable JavaScript function in React that lets us share logic between different components.

Easy example:
Instead of writing the same logic again and again, we put it inside a Custom Hook and reuse it.

Example: useFetch(), useCounter()

In short: Custom Hook = Reusable logic for React components.

2. Lazy Loading

Definition:
Lazy Loading means loading a component or resource only when it is needed, instead of loading everything at the beginning.

Easy example:
If a website has a page called "About", its code can be loaded only when the user opens the About page.

In short: Lazy Loading = Load things only when they are needed.

3. Chunking

Definition:
Chunking means dividing a large application or JavaScript file into smaller pieces (chunks) so that the browser can load only the required parts.

Easy example:
Instead of downloading one huge file containing the whole website, we divide it into smaller files and load them when required.

In short: Chunking = Divide a large file into smaller files for faster loading.
